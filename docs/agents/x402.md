# x402 Monetization

Monetize your AI agents using the x402 payment protocol, allowing you to charge users per message.

## Overview

x402 is a protocol that enables micropayments for API usage. In Spritz, you can enable x402 payments on your agents to charge users for each message they send.

## Enabling x402

1. Edit your agent
2. Navigate to "Capabilities"
3. Enable "x402 Payments"
4. Configure the following:
   - **Price**: Set price in cents per message (e.g., 1 = $0.01)
   - **Network**: Choose your preferred network (default: `base-sepolia`)
   - **Wallet Address**: Your wallet address to receive payments
   - **Pricing Mode**: 
     - `global`: Same price for all users
     - `per-user`: Different prices per user (requires additional setup)

## Pricing Configuration

### Global Pricing

Set a single price that applies to all users. The price is stored in cents:

```json
{
  "x402_enabled": true,
  "x402_price_cents": 1,
  "x402_network": "base-sepolia",
  "x402_wallet_address": "0x...",
  "x402_pricing_mode": "global"
}
```

**Supported Networks:**
- `base-sepolia` (testnet) - USDC: `0x036CbD53842c5426634e7929541eC2318f3dCF7e`
- `base` (mainnet) - USDC: `0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`

### Per-User Pricing

Set different prices for different users (requires custom implementation):

```json
{
  "x402_enabled": true,
  "x402_pricing_mode": "per-user",
  "x402_network": "base-sepolia",
  "x402_wallet_address": "0x..."
}
```

## Public API Endpoint

When x402 is enabled, your agent becomes available via a public API endpoint:

```
POST https://app.spritz.chat/api/public/agents/{agent_id}/chat
```

## Client Integration

External developers can integrate your agent using the x402-fetch wrapper:

### JavaScript/TypeScript

```typescript
import { wrapFetchWithPayment } from "x402-fetch";
import { createWalletClient, http } from "viem";
import { base } from "viem/chains";

// Setup wallet
const walletClient = createWalletClient({
  chain: base,
  transport: http(),
});

// Wrap fetch with x402 payment handling
const fetchWithPay = wrapFetchWithPayment(fetch, walletClient);

// Make a paid request
const response = await fetchWithPay(
  "https://app.spritz.chat/api/public/agents/{agent_id}/chat",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      message: "Hello, agent!",
      sessionId: null, // Optional: maintain conversation context
    }),
  }
);

const data = await response.json();
console.log(data.message);
```

## Payment Flow

1. Client makes a request to the agent endpoint
2. Server calculates the required payment
3. Client signs and sends the payment transaction
4. Server verifies the payment
5. Server processes the agent request
6. Server returns the agent's response

## Supported Networks

- **Base Sepolia** (testnet) - USDC: `0x036CbD53842c5426634e7929541eC2318f3dCF7e`
- **Base** (mainnet) - USDC: `0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`

Note: Currently only Base networks are supported. Ethereum support may be added in the future.

## Best Practices

1. **Fair Pricing**: Set reasonable prices that reflect the value provided
2. **Clear Communication**: Let users know your agent requires payment
3. **Testing**: Test payments on testnet before going live
4. **Error Handling**: Handle payment failures gracefully
5. **Transparency**: Show pricing information clearly

## Troubleshooting

### Payment Not Processing

- Verify your wallet address is correct
- Check that you're on the correct network
- Ensure sufficient funds in the client's wallet

### API Errors

- Verify the agent ID is correct
- Check that x402 is enabled on the agent
- Ensure the request format is correct
